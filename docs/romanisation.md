# House Romanisation Standard

Standard subtitle-grade spellings for contested Hindi words in Roman script. All editors and the pipeline adhere to this standard to ensure consistency across videos and prevent conflicting lexicon promotions.

---

## 1. Questions & Interrogatives

| Canonical | Avoid / Non-standard | Notes |
|---|---|---|
| **kya** | kyaa, keya | Short vowel standard |
| **kyun** | kyon, kyu, kyoon | Standard nasalized termination |
| **kaise** | kese, kaese, kayse | Diphthong standard |
| **kahan** | kahan, kahn | Nasalized 'n' |
| **kidhar** | kidhr | |
| **kitna / kitne / kitni** | kitnaa, kitnee | Gender-inflected standard |
